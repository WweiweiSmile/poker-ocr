# 弃牌曲线探针（P2 第 0 步，2026-11-05）

> 目标不是"校准好"，是**先看信号强度**：本地 + dev 库能凑出多少观测、
> 噪声多大、模型的哪一段和实测对不上。结论比预期更苛刻 —— 见 §4。

## 1 为什么先做这条曲线

GTO 移除后，P2 只剩一条路：用自己打出来的数据校准。而能校准的对象只有

```
f̄(p) = Σ_t  w_t(p) · f_t(p)          p = 下注额 / 他跟注后的底池
```

`f_t`（某档手牌弃多少）**不可识别**：他弃牌时你看不到他的手牌 —— 这是定义，
不是采集缺失。所以能测的只有聚合曲线。工具：`tools/fold_curve_probe.py`。

（订正：早先我说"亮牌只有 24/573 手"，那是在 `hands/1023.hands.json` 上数错了。
全量本地是 **237/573 手有亮牌、341 条两手亮牌**，其中 288 条在河牌上可定档 —— 见 §7。）

## 2 数据与口径

| 来源 | 手数 | 说明 |
|---|---|---|
| `hands/*.json` + `data/hand_outbox/` | 573 | 本地导出的手牌 |
| `replay_imported_hands`（dev MySQL） | 314 | `streets` 是 `potStartBb`/`amountBb` 格式 |
| `review_hands`（dev MySQL） | 53 | 同一套 schema |

**实际可用观测 170 个（弃 95）**。一个观测 = 一名对手面对 Hero 的一次下注/加注，
取他在**下一次加注之前**的动作。口径：

- `price = S/(P+2S)`，`S` = 这次下注的增量，`P` = 下注前底池；
- 短码 all-in 跟注（跟注额 < 应跟额）**剔除**，因为它面对的价格不同；
- 弃牌 = 1，跟注/加注 = 0；
- 多人池里每个对手算一个观测，但它们不独立（弃牌是连乘），CI 偏乐观。

## 4 三条结论（第 3 条最重要）

**① 在 1/2 池上，水平已经基本正确。** 实测 54.2%（CI 44–64%），模型 48.5%（v0）/
46.7%（v1），都落在区间内。这和我上一轮的预期相反 —— 我原以为"校准水平"是最大的
一块肉，实际上 `BASE_FOLD` 的**绝对水平**在最高频的价格点上没有明显偏。

**② 1/3 池是唯一的可疑区间，但样本不够。** 实测 76.9% vs 模型 38.3%，差 38 个点；
可 n=13，CI 50–92%，而且 Hero 的 1/3 池下注本身高度选择化（多在干燥面/强牌时用）。

**③ γ 不可识别 —— 问题在设计，不在数据量。**

```
观测分布：87.1% 落在 0.22–0.32，剩下的桶各只有个位数
```

你自己的下注尺寸策略只覆盖 1/3 ~ 2/3，所以曲线**只有中段有数据**。拟合把 γ 推到
网格下界（0.2 / 0.3），只换来 3% 的 log-loss —— 这是"没有信息"的典型形状，不是
"γ 很小"的证据。

**推论：靠复盘数据永远定不出 γ。** 要定它，只能：
（a）做实验：一段时间内系统性地用 1/4 池和满池/超池，把设计矩阵撑开；
（b）接受先验（v0 的 1.0 / v1 的 0.939），不再尝试拟合。

## 5 对 P0/P1/P2 的影响

- **P0**：不变。
- **P1**：v1 在唯一有样本的桶（0.246）上略差于 v0（46.7% vs 48.5%），但差距在
  CI 内，不足以判定。结论仍是"没有裁判"。
- **P2**：可执行的部分从"拟合 γ"缩到"验证水平 + 记录 1/3 池的异常"。要往前走，
  要么做尺寸实验，要么接受先验。

## 7 意外的发现：摊牌手牌比想象的多

数观测时顺手统计了一遍亮牌覆盖：

| | 数量 |
|---|---|
| 本地手牌 | 573 |
| 有 `shows` 的手 | 237（41%） |
| 两手都亮 | 341 条记录 |
| 河牌 + 两手亮（可定档） | **288** |

河牌摊牌的成牌档分布（用 `range_flow.hand_class` 定档）：

| nut | strong | medium | weak | air |
|---|---|---|---|---|
| 33 (11%) | 63 (22%) | 104 (36%) | 67 (23%) | 21 (7%) |

**这说明另一条路是通的，而且比弃牌曲线更值得做**：摊牌手牌可以**反核范围模型**
（`range_flow` / `field_ranges` 收窄后的 w_t），回答"他在河牌摊牌时，范围里还剩
多少空气/多少强牌"——这正是 `facing_probs` 影响的那一半。

注意偏差：能到摊牌的手天然偏强（空气只有 7%），所以它校准的是**"到摊牌的条件分布"**，
不是全范围。但用它检查"范围模型在河牌是不是把空气留太多"是有效的。

## 8 下一步（按可行性重排）

1. **摊牌反核范围**（288 个样本，可行性最高）：比较「模型预测的河牌范围构成」与
   「摊牌实测构成」，看范围是收得太窄还是太宽。不需要新数据。
2. **1/3 池异常**（n=13）：翻一遍这 13 手的牌面与线路，判断是选择偏差还是模型问题。
3. **尺寸实验**：要定 γ 只能撑开设计矩阵，这是行为改变，不是分析。
