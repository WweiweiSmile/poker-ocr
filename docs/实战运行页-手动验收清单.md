> 本清单负责**只有人眼/真实牌桌能确认**的部分：布局、可读性、实时感、落盘产物。

## 0. 前置

- [ ] `nv tests/run_all.py` 全绿（至少 `test_live_anchor` / `test_live_web` / `test_workbench` / `test_live`）。
- [ ] 已有一个能跑实时链路的工作区（参考 `workspaces/example-wpk-mac.json`）。
- [ ] 牌桌画面可见、识别健康页无红色错误；建议模型可用（或接受兜底建议）。

## 1. 启动

1. `nv -m poker_ocr.workbench` → 打开 `http://127.0.0.1:8030`。
2. 进入工作区 → 运行页 → 点「启动」。
3. 期望：
   - [ ] 运行页出现「运行中」pill，右上「已连接」绿点。
   - [ ] 左栏牌桌随画面更新；右栏建议/错误/事件流/锚点四块都在。
   - [ ] 底部控制台抽屉默认收起。

## 2. AI 建议（实战第一关注点）

- [ ] hero 回合时右栏顶部「当前建议」出现：动作 + 金额、来源 pill（模型/兜底）、理由、plan、事实 chips、对手读数、meta（模型/耗时/置信度/提示词版本）。
- [ ] 模型思考期间显示「AI 正在思考…」+ 已用秒数；出结果后自动替换。
- [ ] 点建议卡可展开完整提示词（System/User/事实/原文/参数），与本帧桌面事实一致。
- [ ] 建议历史（事件流里的建议行）与当前建议不重复、不丢失。
- [ ] 点「复制理由」能把 reason 复制到剪贴板（macOS 弹权限时允许一次即可）。

## 3. 帧识别错误（实战第二关注点）

- [ ] 正常时错误带为绿色「正常」，显示本场丢弃率/牌面 ok/建议跳过/最近错误。
- [ ] 出现丢弃帧时：
  - [ ] 灯变黄/红；「当前段」显示中文类别（如「底池/筹码」）、座位名（如「3 号位 · BTN · 张三」）、帧数、持续秒数（实时跳动）。
  - [ ] 段首事件流出现一行「丢弃 · 类别」，持续更新同一行；结束时标记完成。
  - [ ] 段长 ≥3 帧时行内出现缩略图（第 3 帧），点开可看大图。
  - [ ] 展开「识别错误」详情能看到本场类别计数、接受率、模型兜底率、重连次数、平均耗时。
- [ ] 单帧瞬闪（1–2 帧）也留一行但视觉弱化，不制造噪音。
- [ ] 错误行上的「锚定此帧」可点，点后锚点区新增一条。

## 4. 事件流

- [ ] 默认「重点」视图：建议、错误段、牌面不可靠、手牌、疑惑帧、锚点。
- [ ] 切「全部」：出现逐帧 record、点击/控制事件；切回「重点」不丢已有行。
- [ ] 自动滚底；手动上滚后暂停；点「继续 (n)」恢复并显示积压条数。
- [ ] 长时间运行后行数封顶 500，滚动不卡。
- [ ] 座位名映射正确（`stack:3` → 「3 号位 · BTN · 张三」）。

## 5. 锚点

- [ ] 右栏常驻「⚓ 锚点」按钮：点击后 toast 成功，锚点区新增一条，状态「收集中…」→ 约 3 秒后「已完成」。
- [ ] 错误行「锚定此帧」：落盘中心是那一帧，而不是当前最新帧。
- [ ] 落盘目录 `<run_dir>/anchors/<时间戳>_manual/`，与 `live.states.jsonl` / `live.events.jsonl` / `live.log` 同级。
- [ ] 目录内容：
  - [ ] `frames/NN_e<epoch>_<seq>.jpg` ≥ 20 张（点击前 20 帧 + 点击后 3 秒）；
  - [ ] `meta.json` 含 `schema=live.anchor.v1`、`kind=manual`、`session_id`、`run_id`、`hand_id`、`street`、`center_seq`、`center_epoch`、`frames[]`、`events[]`（±10s）、`console_log[]`（±10s）、`advice`、`table`、`note`；
  - [ ] 点击时帧不足 20 张（刚启动）时 `degraded=true` 且 `ok` 正常返回。
- [ ] 锚点列表最近 10 条；每条可写备注（写 `note.txt`，不动 `meta.json`）、可在 Finder 显示、可打开锚点目录。
- [ ] 备注写完后刷新页面仍在。

## 6. 左栏

- [ ] 「牌桌」tab：座位环、筹码、庄家 D、公共牌、底池、本街下注、hero 手牌、亮牌；空态显示「等待牌桌识别…」。
- [ ] 「实时预览」tab：原预览图 + 选中槽位 inspector；点画面能选中槽位；切回牌桌不丢画布。
- [ ] 「本手行动线」按街分组，hero 行高亮，推断动作带「推断」标记。
- [ ] 「最近手牌」列出最近几手，点开弹窗：概览/行动线/数据质量/建议/范围推导。
- [ ] 范围推导 tab 无 live 时显示空态；有记录时显示 169 格热图与图例。
- [ ] 提示词弹窗（建议卡展开）tab 与内容完整，长文本可滚动。

## 7. 控制台抽屉

- [ ] 点底部「控制台」展开/收起；默认 30 行、等宽字体、自动跟底。
- [ ] 手动上滚后不强制拉回；勾选/取消「自动滚动」生效。

## 8. 看板退役

- [ ] 任何地方都不再有「打开完整看板」入口（run 页 run-head、工作区详情页）。
- [ ] 运行中访问 `http://127.0.0.1:8020/` 返回提示页「看板已并入工作台」+ `:8030` 链接。
- [ ] `:8020` 的 `/api/events`、`/api/snapshot`、`/api/range` 仍可用（SSE 有事件、快照有数据）。

## 9. 故障与降级

- [ ] 停掉 live 后：运行页「未连接」，建议/错误带保留最后状态，锚点按钮报「没有正在运行的 live」（409 toast），不白屏。
- [ ] live 重启后：SSE 自动重连，快照重新播种，不重复建议行。
- [ ] 工作台重启后：页面刷新可恢复，锚点历史仍在（落盘在 run 目录）。
- [ ] 备注/ Finder/错误截图接口都拒绝 run 目录之外的路径（400），不泄露文件系统。

## 10. 记录模板

实跑一场（≥10 分钟）后填写：

```
run_id:                 run 目录:
手牌数:                 建议数:                 丢弃率:
错误段数 / 最长段:      锚点数:                 备注数:
截图: /tmp/...         目录树: tree <run_dir>/anchors | head -40
异常与处理:
```

- [ ] 截图至少三张：建议卡、错误段（带缩略图）、锚点详情。
- [ ] 记录一条锚点的 `meta.json` 关键字段（`center_seq`、`frames` 数、`events` 数）。
