# 提示词「听牌 / 成牌」双规则梳理

> 基线：`lean-zh-2026-11-03.4`（2026-11-02）。范围：live 链路实际渲染的
> `poker_ocr/prompt/system/*` + `poker_ocr/prompt/user/*` + 两处程序建议
> （`attack.py`、`opponent_profile.py` 的桌级/座位剥削文案）。
> `prompt/offline/` 只服务复盘/离线审计，不进 live，本文不列。
>
> 目标：把现在**混在一句里**的规则按「听牌 / 成牌」拆成两套，用
> `sit.hand_tier` 二选一注入；先盘点，再给拆法，最后给迁移步骤。
>
> **落地状态（2026-11-02）**：第 6 节结构已实现于 `lean-zh-2026-11-03.5`——
> `Situation.hand_class` + `prompt/system/hand_type.py`（听牌/成牌+听/成牌/空气），
> 场景段按牌型只渲染对应口径；未全下时听牌价格行不再印四二法则数字。

## TL;DR

现状是**一套规则 + 条件句**：共用 10 条、只听牌 11 条、只成牌 20 条，另有
**12 条混写句**把两套逻辑塞在同一句里（第 4 节逐条给出拆法）。
最大的结构问题不是规则少，而是：成牌没有专属段（20 条散在 7 处）、
半诈唬口径 4 处互相矛盾、combo 同时命中两套、河牌听牌没有落点。

建议改成：`共用段` + `## 当前牌型：听牌 / 成牌 / 空气`（按 `hand_tier` 三选一）
+ `场景段`（多人池/单挑/短码/河牌，每段内部按听/成各写一行）。

## 0. 分流键：什么进听牌集、什么进成牌集

现有分档（`coach.py:424-433`）：

| tier | 含义 | 归哪套 | 说明 |
|---|---|---|---|
| `强听` STRONG_DRAW | 花/顺听 ≥8 outs，或「打牌面+强听」 | 听牌 | ≥8 outs 是现行半诈唬门槛 |
| `弱听` WEAK_DRAW | 真听 4–7 outs | 听牌 | |
| `强成牌` STRONG_MADE | 两对、三条、顺子、同花、葫芦… | 成牌 | |
| `超对` OVERPAIR | 口袋对高于牌面 | 成牌 | |
| `顶对强踢` TPTK | 顶对 + J+ 踢脚 | 成牌 | |
| `顶对弱踢` TP_WEAK | 顶对 + T 及以下踢脚 | 成牌 | |
| `中底对` MID_BOTTOM | 中对/底对/借公对 | 成牌 | |
| `打牌面` BOARD_PLAY | 最好五张全靠公共牌、无听 | 成牌 | 公共牌自己成两对/三条等 |
| `空气` AIR | 无成牌无听（含两高张） | **第三类** | 两套都要能处理，建议单独最小段 |

**交叉情况（现在的漏洞）**：

- **combo draw（有牌又有听）**：tier 仍是成牌类（`OVERPAIR/TPTK/TP_WEAK/MID_BOTTOM`），
  但 `strength.py:46` 与 `scenario.py:95` 都用 `sit.outs >= 8` 判定，
  `scenario.draw_section` 因此会**额外注入听牌段**。结果：combo 同时拿到
  「成牌价值规则」和「听牌默认过牌规则」，两套打架。
- **outs 口径不统一**：`hand.tier` 用 `read.draw_outs`（不含反超 outs），
  提示词里的 combo 判定用 `sit.outs`（含两高张反超 outs，`situation.py:359`）。
  同一手牌可能「tier 说不是听牌、combo 判据说 outs≥8」。
- **打牌面+强听** 会被直接归到 `强听`（`coach.py:618-622`），不再算成牌；
  两套规则需要明确它走听牌集（现状），但「打牌面」本身的摊牌价值会丢。

**建议分流函数**（新代码，规则段用它决定注入哪套）：

```python
def hand_class(sit) -> str:
    tier = sit.hand_tier
    if tier in (STRONG_DRAW, WEAK_DRAW):
        return "draw"                       # 含「打牌面+强听/弱听」
    if tier in (STRONG_MADE, OVERPAIR, TPTK, TP_WEAK, MID_BOTTOM, BOARD_PLAY):
        draw_outs = sit.ground_truth.draws.total_outs if sit.ground_truth else 0
        if draw_outs >= 8:
            return "combo"                  # 成牌集 + 听牌修正，不用 outs（含反超）
        return "made"
    return "air"                            # 高牌/两高张；允许「反超 outs」修饰
```

## 6. 建议结构：两套规则 + 正交局面

### 6.1 system 段布局

```
[共用]  角色 / 输出契约 / 事实优先级 / 数据质量保守线 / 筹码与位置定义
[分流]  ## 当前牌型：听牌        ← hand_class == "draw"
        或 ## 当前牌型：成牌      ← hand_class in ("made", "combo")
        或 ## 当前牌型：空气      ← hand_class == "air"
[场景]  前注 / 多人池 / 单挑 / 短码 / 河牌（每段内部按「听/成」各一行）
```

关键改动不是加段，而是**把「牌型逻辑」和「局面修正」分成两个正交维度**：

- 牌型段回答：这手牌靠什么赢（价值/摊牌/听牌兑现）、下注/跟注/加注的默认动作；
- 场景段回答：这个局面改变什么（人数、位置、SPR、河牌），并且**每条都写清对听牌/成牌各是什么**，不再让听牌规则藏在「下注先问更差的牌会不会跟」这种成牌句里。

### 6.2 两套骨架（建议文字）

**听牌集**

```
## 当前牌型：听牌
- 靠兑现权益赢：下注/加注=半诈唬，跟注=赔率+隐含赔率；河牌未成牌=空气。
- 没有弃牌率时默认过牌（多人池/无位置一律默认过牌）；有**样本达标**
  的弃牌率事实（本街对 c-bet 弃牌率 ≥20 次机会、xr 低、画像）时，
  强听（≥8 outs/坚果听/组合听）可用 1/3–1/2 池小注；样本不足
  （如 3.5 次机会）仍按默认过牌。
- 跟注：未全下/未套池用范围权益+隐含赔率+对手线路；被加注/身后还有人能加注
  时隐含赔率打折；全下/套池才可直接拿四二法则对门槛（短码按即时赔率）。
- 河牌：纯听=空气，只能诈唬（需弃牌率）或弃；不按听牌权益跟注。
- 短码：隐含赔率按 0；SPR≤2 直接用听牌价格行。
```

**成牌集**

```
## 当前牌型：成牌
- 靠摊牌/价值赢：下注/加注=价值（更差的牌会不会跟），没有更差的牌会跟就过牌；
  诈唬只在有事实支撑时做，且不拿「我现在有牌」当跟注理由。
- 跟注：权益直接对门槛（没有隐含赔率）；人多/身后能加注要收紧；
  被加注时看「对手加注范围的构成」（成牌/听牌/空气），不只看权益。
- 多人池：4 人以上顶对/超对降级；两对+ 打光前看公对面；无位置默认过牌控池，
  两对+ 例外；被加注非坚果默认不打三条街。
- 牌面：成花/公对/三条/顺子可能→不能当坚果；公对面葫芦风险；公顺/公花踢脚不参与。
- combo（成牌+≥8 outs）：按成牌逻辑打，听牌只提供保护/半诈唬/后续权益；
  「纯听默认过牌」不适用于 combo。
```

**空气（第三类，最小段）**

```
## 当前牌型：空气
- 没有摊牌价值：过牌/弃牌为主；诈唬必须有弃牌率事实（对 c-bet 弃牌率、画像、xr 低）。
- 河牌：没有摊牌价值，只剩诈唬或弃牌；不按「反超 outs」跟注。
```

### 6.3 每套对 6 个动作的默认

| 动作 | 听牌集 | 成牌集 | 空气 |
|---|---|---|---|
| 无人下注·过牌/下注 | 默认过牌；强听+有弃牌率才小注 | 有价值就下注；无价值过牌 | 默认过牌；有弃牌率才诈唬 |
| 面对下注·跟注 | 范围权益+隐含赔率（未全下） | 权益 vs 门槛；人多收紧 | 只按价格/抓诈，不按 outs |
| 面对下注·加注 | 强听+弃牌率（半诈唬）；否则不加 | 价值加注（强成牌）/保护 | 只在强弃牌率下诈唬加注 |
| 面对全下 | 按发完算；短码按即时赔率 | 权益 vs 门槛；非坚果慎跟 | 弃（除非价格/诈唬证据） |
| 多人池 | 默认过牌（纯听），combo 例外 | 降级/收紧，两对+ 仍打光前看面 | 基本不打 |
| 河牌 | 听牌已死=空气 | 摊牌/价值/被加注按范围 | 诈唬或弃 |
