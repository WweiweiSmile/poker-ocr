## B 组：suited 投机牌面对 limp / over-limp 例外

`#42`（2026-11-16.2）之后，白名单（22–66 小对子、A2s–A9s、K2s–K9s、
两张都 ≤T 且间隔 ≤2 的同花连张/隔张）在 **CO / BTN / SB**、`to_call ≤ 1BB`、
且身后隔离率 <20%（≥16 次机会）时可以 1BB 平跟；其余仍按「入池就加注」。

## 5. 覆盖缺口（按优先级）

1. **面对 3bet：完全空白。** 0 条 spec，0 条案例；现有 17 个 preflop 锚点
   只覆盖 limped / single-raise 的 raise / call / check / fold。
2. **sizing 与 freq 全空。** 77 条 spec 的 `sizing` / `freq` 都是 null。
   `scoring.size_score` 已支持 `{unit:"pot_fraction"|"bb", min, max}` 的带，
   但没有数据在用；「中了牌拿多少」目前只能判动作。
3. **桶维度基本没用起来。** 73/77 条 bucket 只有 `street`。`case_candidates`
   API 按七维桶取候选，但 spec 不按桶建，候选池和评分口径对不上。
4. **over-limp 例外上线太新。** `#42` 2026-11-16.2 才进提示词，现有 limped
   锚点都是之前的口径；B1 的 7 手正好横跨政策切换。
