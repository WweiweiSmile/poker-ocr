# 提示词紧弱纠偏：从「数据开关」改成「EV 比较」（2026-11-04.2）

## 现象

11-04.1 之后模型明显偏紧弱：翻后大量过牌，听牌不半诈唬，边缘价值不打，
理由多是「没有该街弃牌率 / 没有画像」。这不是模型胆小，是提示词把
「有没有实测样本」写成了下注许可。

## 根因（三条，都在提示词里）

1. **许可被写成数据开关**：听牌要「L2+ 且每个仍能行动的对手实测 ≥50%」，
   空气要「L3 + 每个对手 ≥50% 实测」。现场画像通常只有 6–12 次机会，
   等于永久禁止半诈唬与诈唬。
2. **条件弃牌率没进提示词**：`poker_ocr/fold_equity.py` 早就按「本手线路
   剩什么范围」算了逐尺寸弃牌率、盈亏平衡点与 EV，但只服务离线英文
   提示词（`prompt/offline`）和审计，中文 lean 事实块里一行都没有。
   模型只能拿「全范围历史平均」猜，而这个数在本手线路上经常是错的。
3. **攻击块只认逐座位实测**：11-04.1 删掉桌况合并后，攻击块要求每个
   在局对手都有该街 `fold_to_bet_*` 实测；没有画像就落到「仅可下注价值牌」。
   本次**没有**放宽它：攻击块只覆盖「多人溜入池 + Hero 收尾」，多人池的
   诈唬 EV 是「全部弃牌」的连乘，逐尺寸 EV 没有建模，凭先验放开会鼓励
   -EV 的开火。它仍然是「价值下注可以、空气小注要实测」的口径。

## 改法

- **新增恒定段「攻击口径」**（`prompt/system/aggression.py`）：下注/加注
  看 EV，不看待测样本量；他弃 ≥ 需要 → 该尺寸 +EV；尺寸先小后大；
  实测与画像只用来校准，不是开火开关；薄价值按「你赢的」比例打。
- **尺度阶梯**（`arbitration.py` #4）：L1 只支撑 ≤1/2 池，L2 到 2/3–3/4，
  L3 才用于大注/全下/多街。先验/低样本仍不得触发大注。
- **新增事实段「范围弱点与弃牌率」**（`prompt/user/exploit.py`）：
  本手线路剩多少组合、强成牌/空气占比、全部弃牌概率（与历史平均并排，
  并说明「线路已拿掉弱牌」还是「比历史更会弃」）、逐尺寸「他弃 / 需要 /
  EV」、面对下注时的跟注 EV。攻击块出现的节点不渲染，避免两套结论。
- 同步改口：听牌/空气/单挑/多人池/河牌场景段、输出契约与数据质量段的
  「缺口只降低诈唬频率」都改成「降低尺寸与频率，不禁止有 EV 依据的小注」。

## 行为差异（典型局面）

AK 在 K72 彩虹面、单加注池、对手过牌：之前「没有该街弃牌率 → 只能过牌」；
现在事实块直接给出「1/3 池他弃 48% / 不需要弃牌率（被跟也赚）/ EV +8.7BB」，
以及跟注 EV 与「你领先 95.7%」，模型有依据选更凶的线，同时看得到被跟后的权益。

## 验证与回滚

- `tests/test_advice.py`：新增条件弃牌率兜底与事实段用例；改动两处
  仍按旧措辞断言的用例。
- `replay-console/tests/test_prompt_golden.py`：版本与 hash 已随
  `lean-zh-2026-11-04.2` 更新。
- 回滚：把 `PROMPT_VERSION` 退回 `lean-zh-2026-11-04.1`，并还原
  `system/aggression.py` 的注册与 `user/__init__.py` 的 exploit 段即可；
  事实层与规则层是分开的，可以只留事实层。

## 还能往哪调（按优先级）

1. 跑 A/B 手牌集，看翻后 bet/raise 频率与「薄价值」占比；如果仍偏紧，
   把 `_MADE_COMMON` 的薄价值条件从「你赢的够多」量化成具体百分比。
2. 溜入池没有范围（OCR 对不上底池）时，攻击块仍只能「仅价值下注」；
   可以接人群先验（`DEFAULT_PRIORS` 的 `fold_to_bet_*`）做兜底，但要把
   「多人池全弃是连乘」写进结论，避免把 45% 当成人人都弃。
3. 翻前偏紧是另一条线（范围表 + 对手开池宽度），不在本次改动里。
