# 摊牌证据行·三版对比稿（prototype，2026-11-14）

一句话：判断「他在{街}{位置}{行动}时亮过{族}（N 次）」这句话，读起来像**证据**，还是像**频率/结论**，会不会被模型或人误读。

## 0. 口径先说清楚

- 数据：970 手（data/hand_outbox/，2026-11-13 快照）。池级数字用 **#19 严格口径**（最后动作 fold，或不在最后街 street_active，任一即拒）：453 条 / 280 手 / 86 人；河牌亮牌 397 条；弱A顶对 6 条（河牌 5、河牌 IP 过牌 3）。
- 票面指定样本 20261030-aa15e0bbff **不在严格口径里**：河牌 street_active=[hero,lowL] 不含河牌下注的 midL，字段自相矛盾 ⇒ 本稿三版是**句式样稿**，不是严格口径下真会渲染的句子；真会渲染的同类句见 §3。

## 1. 样本事实（票面指定）

对手「我爱恰饭饭」UTG+1，河牌面 As 6d 2c Js Kd 上**下注 24**；随后 hero(BB) 与 lowL(UTG) 从行动集里消失（这手没有摊牌，只有他一人亮牌）。
他亮 **Ac 3c**：A 高牌面顶对、踢脚 3 ⇒ 族 = 弱A顶对。相对 hero 位置：**IP**（翻后他在 hero 之后行动）。
clean 口径（只否决 fold）下，该格（弱A顶对 × 河牌 × IP × 主动下注）只有这 1 条，样本本身是孤例。

## 2. 三版（你要选一句）

**V1 纯事实**

> 他在河牌 IP 主动下注时亮过弱A顶对（1 次）。

- 多给的信息：无。它只声称「发生过一次」。
- 读感风险：读者可能嫌信息少、追问「1 次能说明什么」——这正是 #17 要的（N<3 只当事例读）。

**V2 纯事实 + 池级对照**

> 他在河牌 IP 主动下注时亮过弱A顶对（1 次）；这个池子河牌亮牌里，弱A顶对只见过 5 次（本池）。

- 多给的信息：这个族在池里很罕见 ⇒ 读者可能读成「所以他这样打很反常、值得注意」。
- 代价：跨层拼接。#17 的触发表里「个人该 spot 有证据」时不再出池级行；且 5 次 < 20，按 #12/#17 不该出数。采用 V2 = 新增一条触发规则。

**V3 纯事实 + 建议**

> 他在河牌 IP 主动下注时亮过弱A顶对（1 次）→ 他河牌下注不一定是强牌，你可以用中等牌力多跟一手。

- 多给的信息：直接给打法。
- 代价：把 1 次亮牌升级成范围结论；且这是主动秀样本（打跑对手才亮，偏 Show），违反「模型只能引用事实、不能拿标签替代证据」。
