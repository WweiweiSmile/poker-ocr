本原型暴露的 schema / 口径缺口（点开，5 条）
  1. 逐 combo 数据只有 top 榜：若 T2 只存 top_lost / top_gained，点热图格子无法列出该格全部组合——中间步骤只能给出占比与少量样例。要支持「点格子筛 combo」，trace 需按 169 键存 top_by_key（每格 top 3），或提供按需重算接口。本原型点格子大部分会空，就是为了把这条摆出来。
  2. 同一手牌并存两种口径：没有翻后动作的座位走 board_range 旧路径（有宽度、没有逐事件 trace），有动作的座位走事件模型。看板必须逐座位标出口径来源，否则「A 家 22.6%、B 家 81.5%」看起来像同一把尺子量出来的。
  3. 没有筹码量就没有 SPR：hands 归档缺 hero_stack / 对手 stack，这次全部退化成 SPR=99（spr_bucket 恒为 high）。live 快照有 stack，但 T2 仍应把每个事件的 spr 与 spr_bucket 落盘，否则看板解释不了「为什么这一步压得这么狠」。
  4. 没有 prior 版本的 diff：换表前后对照需要 trace 带 prior.id + prior.version + table_profile，当前只有 prior.id。原型只能给单版本视图，diff 留 #9。
  5. 没有「提示词那句话」的锚点：equity 条要能跳到提示词引用它的那句，需要 trace/advice 侧提供 prompt_ref（段落 id 或行号），现在只能跳到整个「建议」tab。
