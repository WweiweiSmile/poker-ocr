### 1.1 `51d037ec76` CO 8♥6♥ —— 跟 3-bet 40BB，本日最贵的一口

```
前注 0.5，hero 后手 91BB
upR limp 1 → hero 隔离到 7 → lowL 跟 7 → upL(SB) 3-bet 到 40 → hero 跟 33 → lowL 跟 33
翻牌 Ac 8d Kd，pot 125.5 → upL 直接 bet 393.5 ALL-IN（盖住 hero 后手 51）
```

- **AI 的建议**：`call 33BB`，confidence 0.6，理由「86s 在 3-bet 继续范围内，
  赔率门槛 35.7%，有效筹码 49.5BB 有隐含赔率」。hero 照做。
- **问题**：这是 SB 从 7 **加到 40（5.7 倍）** 的大 3-bet，不是 3 倍标准 3-bet。
  跟 33 之后只剩 51BB、SPR≈0.4，翻后没有任何操作空间；而跟注的隐含赔率需要
  约 12:1，你天花板是「再赢 51 + 池里 125 = 176」，实际只有 5.3:1 —— **数学上不成立**。
  35.7% 这个门槛算的是 hot/cold 权益，86s 的实现权益（被 A/K/Q 盖帽、中底对也
  不敢加注）远低于它。
- **正确打法**：**弃牌**。想玩只能在小 3-bet（≤3.5x）且后手 ≥100BB 时用。
- **这是建议层的 bug，不是 hero 手滑**：`prompt` 里的「3-bet 继续范围」没有按
  3-bet 尺度、后手、位置收缩。一手就蒸发 40BB。

  但合起来是 **98BB 换一条约 30% 的听牌**，而且：
  - 翻牌就以「中以对 + 两头顺」在 4 人池里 1/3 下注，被翻前加注者加注后仍跟；
  - 转牌对手明显有牌（加注过的翻前加注者），hero 却继续投 50 去追 8 张顺。

  真实局面对手是 4 人池里翻前加注、翻牌加注过的人，他的 Qx/KQ/两对大量占据你的

## 2. 系统性问题（比单手更值钱）

1. **3-bet 继续范围不看尺度**：`51d037ec76` 那种 5.7 倍 3-bet 仍然被判「在继续范围内」。
   应按 3-bet 倍率、后手、位置三档收缩；大 3-bet 时同花连张直接移出范围。
2. **低权益模板化**：`equity ≤ 16%` 时 1/3–1/2 是负 EV 模板（当日 4 次 0% 权益下注）。
   应该给「过牌」或「≥2/3 池 / 全下」的二选一，而不是继续填中间档。
3. **多人池 + 无位置的小注半诈唬**没有弃牌率（`a118a01e60` 4 人池 1/3 下注），
   这类位置应该默认关掉 1/3 档。
4. **记录质量**：33/55 手带 warning，`a118a01e60` 转牌金额 `0/0` 而 pot 涨 100，
   `3755569db1` 翻牌出现「弃了又跟」的拼帧动作。建议 `hand_track` 层加两条硬校验：
   同一座位同一街动作倒退 = 丢帧；金额为 0 但 pot 增长 = 记 error 而非静默接受。
5. **`hero_stack_bb` 不能当盈亏曲线**：`20:54:59`、`21:04:10` 各 +99.5，
   `21:16:41` +48.5，是补码/重新带入的跳变，不是输赢。

## 3. 已修：面对全下 / 只剩全下可加注时建议卡死

根因：`preset_text` 判据只认「数字 + BB」的预设行；只剩全下时这一整行不渲染。

修法（`poker_ocr/roi_reader.py`）：
- `measure_hero_turn` 的 `preset_text` 路径加兜底 —— 探针读空（或读到非 BB 文本）时，
  再看底部右侧动作键的**蓝占比**（`right_blue ≥ 0.15` → `True`）。
  只看蓝不看红：预选弃牌时左侧也会亮红。
- `_hero_action_slots()`：每侧同时看 profile 槽位（web：`hero_call_button` /
  `hero_fold_button`）和手机硬编码矩形，取占比大的 —— 归一化坐标跟宽高比走，
  web 的 pill 在 x 0.58–0.64，手机矩形从 0.66 起会读到毛毡。
- 测试：`tests/test_roi_reader.py::test_preset_text_falls_back_to_right_button_on_web_layout`
  （右蓝 → True；纯毛毡 → False；只有左键红 → False；`ALLIN` 文本 + 右蓝 → True）。
- 文档：`docs/live-stream.md` 的「轮到我」判据段、`SYSTEM.md` 陷阱段已同步。
- `nv tests/run_all.py` → 67 个套件全过。
