## 2 B：池子先验兜底（提示词 11-04.4）

新增事实段 `prompt/user/pool.py`：**逐座位缺该街实测**（含被先验收缩的估计）时，
给一条池子级弃牌率 + 盈亏平衡对照，并写明「这是池子均值，不是这个座位」。

触发条件（三者同时成立才渲染）：

1. 翻后，且当前没人下注（要轮到我们决定下不下注）；
2. 至少一名在局、还能行动的对手没有该街实测；
3. 事实块没有给出逐尺寸 EV（有的话已经覆盖同一节点），攻击块也没给裁决。

实际渲染（3 人池、无画像）：

```
## 池子先验（逐座位数据缺失时的兜底，不是这个座位）
- 面对翻牌下注弃 78%（495 次机会）；口径：对手库全场加权（51 人 / 4153 手）
- 对照：1/3 池需要 25%、1/2 池需要 33%、2/3 池需要 40% 弃牌率才 +EV（单街，不算被跟后的权益）
- 多人池按连乘打折（独立粗算）：2 家 ≈61%、3 家 ≈47%、4 家 ≈37%；3 家以上只用来支撑价值/强听小注，空气不要拿这条开火
- 用法：某个座位没有该街实测时按这条估计，不要因为「没有这个人的数据」就默认过牌；大注仍要 L2–L3 与实测
```

数据来源优先级：`sit.table_stats`（本手在局对手画像合并，n≥20）→ 对手库全场加权
→ `DEFAULT_PRIORS`。

### 3.1 一次过冲和它的补丁

`.4` 首轮复跑里，模型开始拿「池子弃 78%」在 **5 人池用空气 1/3 池开火**（3 手，
理由是「78% 远超所需 25%」）。问题不在数字，在**没做连乘**：78% 是「每个对手」
的弃牌率，5 人池全弃粗算只有 0.78⁴ ≈ 37%。

补丁（仍在 11-04.4 内）：池子先验段加一行连乘对照——
「2 家 ≈61%、3 家 ≈47%、4 家 ≈37%；3 家以上只用来支撑价值/强听小注，空气不要拿
这条开火」。复跑后**5 人池空气开火 = 0 手**，整体激进率从 25% 回落到 21%。

## 4 口径与坑

- 复跑会跳过陈旧帧，对齐时用「旧建议 id」匹配，不按顺序 zip；匹配不上的决策点不计入。
- 手级净值只在每手的第一条翻后建议节点上计一次，避免同一手被多个节点重复统计。
- 池子先验的 78% 是**对手库全场加权**（51 人 / 4153 手），不是单桌实时；单桌数据够时优先单桌。
- 池子均值是「每个对手」的弃牌率，**多人池必须连乘**；这是第一次复跑抓到的过冲点。
- 早几天 hero 弃牌没入账，所以「面对下注弃牌率」只有 11-04 可测；其余节点不受影响。
