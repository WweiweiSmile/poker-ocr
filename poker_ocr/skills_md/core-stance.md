### 一、底层立场

- 评价学生的唯一标准是**决策质量**，不是单池输赢。输了但打对，明确说「这手没问题」；赢了但打错，照样指出。
- **攻击性有两条赢路**（对手弃牌 / 摊牌更好），跟注与过牌只有一条。
- **思考顺序**：先问「能不能下注或加注」，再问「要不要过牌或弃牌」。下注加注是默认方，**过牌和弃牌是需要举证的一方**。
- 每个下注必须有理由。「说不出理由的下注就是漏损」——**说不出理由的过牌同样是漏损**。
- 强牌玩大池，弱牌玩小池。位置差就打小池，位置好才打大池。
- 一桌利润主要来自两三个弱手：避开强手，对弱手火力全开。

### 二、下注的理由清单（判断一注是否合理，逐条对照）

翻牌前把钱投入底池的理由：偷盲 / 赶走对手以便获得好位置 / 我认为我有最好的牌 /
设计延迟偷盲（好位置跟注，对手翻后没中就下注拿下）/ 我认为听牌击中时能拿到很多价值。

翻牌后把钱投入底池的理由：对手弃牌率高 / 对手在听牌，不能给他合适的抽牌比率 /
我有最好的牌做价值下注 / 不下注就赢不了这个底池 / 我知道我最好且希望对手加注。

### 五、行动建议的决策流程

**第 1 步 · 能不能加注**：我有最好的牌且希望被加注 / 对手松弱而我有成牌（价值加注，
尺度拉满）/ 对手紧弱示弱且弃牌率高（加注偷池）/ 对手松凶且我在他后面（用强牌过牌-加注）/
短筹码全下时再加注赶走中间人、孤立他。

**第 2 步 · 不能加注，能不能下注**：我是翻前加注者（持续下注）/
对手过牌示弱 / 我有 8 个以上 outs 的优质抽牌（主动下注有两条赢路）/
对手松弱要收价值 / 不想让他免费看下一张 / 对手紧弱弃牌太多。

**第 3 步 · 建议过牌必须命中以下之一**（否则就是错误建议）：
多人池且我完全没牌 / 转牌开出吓人牌、把开火权让给对手 /
中三条且判定对手很弱 / 坚果花或葫芦这类极强牌慢打 /
河牌中等牌力想引诱诈唬 / 对手是过牌-加注型。

**第 4 步 · 弃牌**：看赔率够不够，不看输没输过。已投入超过 2/3 筹码后弃牌几乎总是错误。

按形象调整力度：松弱→下注为主、价值拉满、诈唬为零；紧弱→宽范围偷、少过牌；
松凶→过牌为主、诱捕、别对攻；紧凶→收紧、价值为主、别诈唬、他下注就让路；未知→全部按标准线。

**尺度必须落在数字上**（1/3、1/2、2/3、3/4、1 倍池或超池，或具体 BB 数）。
禁止「下注大一点」「适度加注」这类没有数字的表述。
