### 三、对手形象：五格分类

按「松/紧 × 凶/弱」定位，另加一个「未知」格。

| 形象 | 识别特征 | 剥削方案 |
|---|---|---|
| 松弱（跟注站） | 跟注多、加注少，什么价都跟 | **永不诈唬、永不慢打**。纯价值下注，强牌下重注 |
| 紧弱（岩石） | 入池率低，遇压力就弃 | 打松偷他的池；他终于下注就立刻弃牌 |
| 松凶（LAG） | 频繁下注加注，多重连发诈唬；**但他制造小池时反而危险** | 停止对攻。持强牌过牌-跟注让他自毁；放弃小池，等他强牌时赢大的 |
| 紧凶（TAG） | 入池率低但下注加注频繁，尺度合理，很少被动跟注 | 避开，减少诈唬。**他翻后跟注重注 = 几乎一定在慢打强牌** |
| 未知 | 同一模式样本不足 3 次 | **按标准线评判，不做剥削性偏离** |

硬规则：
1. **单一手牌不足以定性**。同一模式出现 3-4 次才算「可剥削」。样本不足就归「未知」。
2. **「未知」不等于「弱」**。对未知对手的剥削性偏离，本身就是送给对手的机会。
3. 每条建议都要指明「针对哪个形象、利用哪个倾向」，不给放之四海皆准的建议。

六种可剥削的下注模式：有大牌就下注没牌就过牌（他过牌我就下注）/ 听牌时就下注（听牌面下大注）/
翻前加注后持续下注控池（我有位置强牌时跟注设陷阱）/ **只有一发子弹**（翻牌跟注，
转牌他下注说明我已被击败、他过牌说明底池是我的）/ 诈唬时下重注（河牌重注我跟）/
有弱牌时下小注（他下小注我就加注）。

### 四、对手手牌范围推断

本书是 2005 年的作品，教的是「猜到对手的底牌」，不是现代意义的组合范围平衡。
以下四条线索来自书中，**范围化的表述属于合理引申**，不要编造书中没有的范围理论。

**线索一 · 位置**：越靠后入池范围越宽。前位加注=强范围；后位加注可能是偷盲。
CO 位加注通常比 BTN 位强（BTN 偷盲已是行业标准）。

**线索二 · 下注尺度**：尺度小=想要跟注；尺度大=想要弃牌或保护容易受伤的牌。
**尺度异常是最大的信号**，但必须先确认这个对手属于「强牌下小注」还是「强牌下大注」型
——书里明确说两种人都有，不能假设。

**线索三 · 过牌**：默认是「翻牌没中」的象征，但必须区分三种：
示弱过牌（准备弃，我下注拿下）/ 陷阱过牌（强牌等我下注，谨慎）/
听牌过牌（想免费看牌，别给）。**多人池里的过牌比单挑里的更可信**。

**线索四 · 加注与再加注**：书里最直接的推理是
——**一个人没做的动作，和做了的动作一样有信息量**：
跟注的人通常没有能再加注的牌，否则他刚才就自己加注了。

合成顺序：翻前给出粗略范围 → 逐街看他保留了范围里的哪些部分、去掉了哪些部分
→ 用牌面结构交叉验证（这张牌帮到了他范围里的多少）。

**河牌翻转规律**：前面打得软弱、河牌突然下一个可疑大注 = 诈唬；
前面打得积极、河牌突然变得胆怯 = 陷阱；又积极又像在试探 = 中等牌、没把握。

禁止：把范围说成确定的牌（「他有 AA」）；样本不足 3 次就谈「他的范围」；
凭单条线索下强判断（至少三条线索同向）；用摊牌结果倒推他当时的范围。
