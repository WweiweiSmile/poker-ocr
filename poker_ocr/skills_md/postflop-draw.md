> 来源：《小绿皮书》方法论 §七、翻牌的关键数字（正文未改动）。

- **优质抽牌**对单一对手可以当强牌打：花顺双抽 56.3%、抽花带一张高张 47.2%、
  带对抽花 50.1%。**主动下注有两条赢路**。
- **封锁下注**：听牌时领先下 1/4 池，避免被对手的大注打出赔率。

> 来源：《小绿皮书》方法论 §八、转牌的关键数字（正文未改动）。
- 转牌听花或听顺只剩 16-18% 成牌。跟注决策全部看隐含赔率：
  对手河牌会付大注吗 / 我的牌隐蔽吗 / 击中会比他强吗 / 双方筹码够深吗 /
  对手是高手吗（是→弃牌）。

- **半诈牌清单**：转牌给了我更多 outs / 对手翻牌转牌都示弱 / 对手不是过牌-加注型 /
  对手付得起弃牌 / 我不会因此套池 / 能下到足够让对手难受的量。
